dsh-poison-guard

Pre-install supply-chain poison scanner for DeepSeek Harness plugins — AST (JS-X-Ray) + deobfuscation + regex heuristics, not a toy grep.

dsh plugin add dsh-poison-guard npm install -g dsh-poison-guard

What it detects

SeverityExamples
HIGHdata-exfiltration, unsafe-import, unsafe-stmt (eval/Function/vm), unsafe-command, deobfuscated-secret/key/command, exfil-combo, private-key paths
MEDIUMserialize-environment, shady-link, sql-injection, monkey-patch, prototype-pollution, deobfuscated-url, network egress, install-time scripts
LOWencoded-literal, short-identifiers, unsafe-regex, weak crypto, env-read, base64 obfuscation
Honest threat model: no static tool catches all poisoning — detecting arbitrary malicious behavior is undecidable (Rice's theorem). This makes the cheap, high-volume attacks visible. The real boundary is the DSH sandbox: keep untrusted plugins in workspace-write, never danger-full-access.
